# 播中播后综合 Agent 新首期方案

本目录是2026年10月20日的新设计，不替换上层旧播中、播后方案，不包含Agent业务实现。

用户已确认可以手动导出经营报表。标准路径为：播中程序监控 → 完整按场归档 → 关播后导入授权经营报表 → 程序计算指标 → Agent按证据复盘 → 用户选择下一场建议。没有自动插播、切品、改稿、重排、改价或发券功能。
