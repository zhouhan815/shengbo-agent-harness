# 播中播后综合 Agent 新首期方案

最新开发入口：[完整Harness工程计划](engineering-v1/播中播后综合Agent完整工程计划.html)（LIVE-REVIEW-ENG-1.0）；源文件与分工见[工程包README](engineering-v1/README.md)。已将数值评价纳入数据、工具、主子Agent、中间件、接口、恢复及验收，包含18项播前迭代预防映射、50项拟验收场景与34个指标执行配方。**本次只完成设计，尚未实施新的Review业务代码。**

总体阅读版：LIVE-REVIEW-1.1，数值评分政策LIVE-SCORE-0.1。原1.0稿保存在history/LIVE-REVIEW-1.0-before-numeric-scoring。所有评分锚点是待真实数据校准的项目设计值，不是行业标准；旧Schema是设计示例，具体字段收口与新DTO导出要求以工程包为准。

本目录是2026年10月20日的新设计，不替换上层旧播中、播后方案，不包含Agent业务实现。

用户已确认可以手动导出经营报表。标准路径为：播中程序监控 → 完整按场归档 → 关播后导入授权经营报表 → 程序计算指标 → Agent按证据复盘 → 用户选择下一场建议。没有自动插播、切品、改稿、重排、改价或发券功能。
