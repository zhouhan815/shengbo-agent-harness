## 本包的统一决定

一个主复盘Agent，两个按需专题子Agent，四个自定义业务中间件、四份角色内按需Skill、十四个原子业务工具和五个可选组合工具。SDK的计划、文件、摘要和子任务机制另按固定版本配置，不当成自定义中间件数量。确定性统计、采集、导入是普通服务。

播中只监控；播后分析；采纳由人工确认。Agent可以选择和组合工具、追加调查，不必按F01→F05固定跑一遍。工具内部的数据顺序、权限、金额口径、版本与确认是确定性规则。

## 本次完成与尚未验证

本次做设计整合、源码／版本核对、独立复核和文档静态检查。SDK报告中的纯假模型探针只验证框架控制行为。所有W、R、PL业务验收属于后续实施，不能因写了验收表就声称已经通过。

实际经营表表头、平台声音／事件延迟、真实历史基线和新Review总耗时仍需实施验证。10分钟是数据就绪后分析交付的优化目标，不包含一小时直播本身，也不是已测承诺。

静态核对结果见[工程计划静态核对记录](工程计划静态核对记录.json)；过程与修订收口见[独立复核收口](research/工程计划独立复核收口.md)。
