# Agent 主体前端纠正与验收

日期：2026-10-16。以用户提供的《声播播前Agent前端方案与后端交接说明.md》交互语义为准；实际业务仍采用 PRELIVE-2.3，不照搬该文件的假设接口。

## 页面主次与入口

默认 `/` 和桌面“声播”快捷方式进入 Agent 工作台。右侧是完整对话，左侧是成果和人工微调；原声播控制台移到 `/studio`，用于声音播出、逐句监控和既有调试功能。运行中的业务、商品库、声音文件不为这次布局改造复制或迁移。

| 原方案要求 | 本轮实现 | 验证方式 |
|---|---|---|
| Agent 为主体 | 独立工作台，未加载旧主站控制脚本或悬浮助手 | 真实首页及浏览器检查 |
| 左右点击与键盘聚焦 | 对话聚焦约40:60；成果聚焦约65:35 | 宽度测量、键盘与点击测试 |
| 不因聚焦丢状态 | 修改布局属性，保留编辑器 DOM、光标、输入和滚动 | 同一 DOM、选区与草稿断言 |
| 窄屏可使用 | 800px以下切换成果／对话，保留同一状态 | 1440/1024/768/390/320px |
| 左侧直接编辑 | 商品完整字段、本场配置、研究建议、模块话术、播放项和人工采用 | 隔离真实业务服务链路 |
| 点选精确修改 | 明确按钮绑定精确 ref、字段或模块原文 hash；普通点击不绑定 | 前端冻结、后端范围校验 |
| 页面与任务隔离 | 页面导航保留会话；提交固定对象、版本、目标范围 | 跨商品导航与提交测试 |
| 未保存内容保护 | 本机恢复缓冲；选中对象 dirty 时发送前选择保存、放弃或返回 | 刷新恢复与并发发送测试 |
| 成果原位呈现 | 数据式目标映射到左侧；不执行模型 URL；更新后重读时保留 dirty | 成果定位与安全刷新测试 |
| 后台不抢焦点 | 新消息、进度、hover不放大另一边；自动跟随默认关闭 | 后台进度和跟随保护测试 |
| 执行过程开关 | 对话内分块展示主/子任务、工具参数与结果；关闭只隐藏 | 既有助手回归与新工作台测试 |

## 实现文件与边界

- `ecommerce-voice-agent/web/agent-workbench.html`、`.css`：页面结构、宽度、窄屏布局。
- `agent-workbench.js`：左右聚焦、页面导航、会话绑定、明确选择、dirty 发送确认、成果跟随。
- `workspace-editors.js`：使用同一套真实业务命令的左侧编辑器，无旧控制台全局变量依赖。
- `workbench-api.js`：本机 CSRF 会话、标准命令／查询、明确未知提交结果，不盲目重发写操作。
- `assistant.js`：保留已有过程卡片与消息协议，增加宿主回调和单飞提交，复用资料上传。
- `shengbo-ops-agent/src/shengbo_prelive/selection.py`：把明确目标放入上下文和写约束，不仅显示一枚前端标签。
- `app/server.py`：默认入口改为 Agent 工作台，原执行台保留 `/studio`。

左侧和 Agent 共用权威业务服务；本场引用共享商品版本。候选、人工批准、生成语音、采用、开播仍是不同动作；换 UI 不提升模型权限。

## 验收证据

初轮独立 Chromium 工作台检查27项通过；编辑器独立检查42项通过。另执行34项真实临时数据库和真实路由的浏览器人工链路，覆盖商品、本场、模块、编排、文案批准、音频任务、候选与采用；此链路的外部文案与 WAV 适配器为明确模拟。

声播隔离 Python 完整回归215项通过；Agent完整回归123项与7个subtests通过，新增8项显式选择约束测试；助手原有消费者断言回归通过。最终增补项与机器结果见：

- `ecommerce-voice-agent/verification/Agent主体前端原方案核对.md`
- `ecommerce-voice-agent/verification/agent-workbench-ui/`
- `shengbo-ops-agent/tests/test_selection_binding.py`

正式本机页面已使用现有商品和直播间做只读界面核验，截图分别为 `actual-agent-chat.png` 与 `actual-results-focus.png`。桌面快捷方式保持调用原 launcher；首页地址不变，默认内容已改变。

这次普通验收没有调用真实模型或付费 TTS，没有修改正式商品资料，也没有对外推流。OBS 和真实成交效果不属于本次 UI 验收结论。

## 后续维护规则

改前端时必须同时运行焦点、目标绑定、dirty、成果定位和真实业务临时库联调；不能只验证一张静态截图。历史第18号记录的旧侧栏／弹窗截图不再代表当前默认首页。

最终补验：历史研究需由人明确复核后另存到本场，不能将旧场分析引用伪装为当前可改目标；研究保存后的选择续绑真实新 analysis_ref。服务8765/8791健康，桌面 launcher重复调用复用服务；默认首页与 /studio 分别返回 Agent 和原播出执行界面。
