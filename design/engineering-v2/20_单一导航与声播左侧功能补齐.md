# 单一导航与声播左侧功能补齐

2026-10-16。用户最新要求：移除顶部直播间／本场下拉和重复创建操作；依照原前端方案的 NotebookLM 式工作区，Agent 对话为主体，左侧可进行原声播的实际操作。

## 实际改动

顶部只保留商品库／直播间入口及当前范围的只读文字。直播间在左侧用卡片选择，进入后展示历史本场、一个新建本场表单、复制入口及长期默认设置；复制不会默认继承过期或未确认的活动。

左侧的播前编辑器补齐：默认声音与版本数、完整全场优惠作用范围、单品互斥和叠加、赠品与发货覆盖、本场知识文档、未保存优惠的金额预览、单品生成1—6版、音色示例试听、商品图片与归档。长期默认设置和本场配置分别保存；金额预览按本场所引用商品修订计算。

左侧新增四个实际执行视图，不用旧站 iframe 替代：

| 视图 | 操作 |
|---|---|
| 播出监控 | 当前商品／版本／句子、暂停继续、下一句／品、重播、结束、待播调整、人工插播、OBS 链接、声音来源接管、静音画面预览、执行记录 |
| 平台接入 | 配置公开来源、开始／停止采集、重连、状态和实际事件；真实与模拟分开 |
| 评论测试 | 会话、发送测试问题、知识与引用依据、失败重试、模拟进入／点赞、导出 |
| 任务与评测 | 任务进度、失败／未知结果、重试门槛、已有话术评测与语音样本 |

主界面只显示一套执行导航。执行区媒体对象跨视图保留，离开视图不等于停止播出或采集。平台配置、评论和插播的未提交内容也参与自动跟随与离页保护。

新增四个人工专用 API：`room-settings`、`product-archive`、`price-preview`、`voice-preview`，位于 `/api/prelive/v2/human/`。这些不加入 Agent 工具；本机来源、Cookie 与 CSRF 校验沿用真实业务门面。设置及归档带精确版本、操作编号和事务回执；未知写入结果先查回执。独立固定示例试听不改变本场稿件需整包批准的规则。

## 视觉与交互

压缩顶部，灰白纸张背景、圆角双区、较清晰的文字与编辑分组；聚焦比例仍为对话40:60、成果65:35，窄屏切换同一份成果／对话状态。字段配置中的币种、声音等选择仍保留；去掉的是用户指出的顶部范围下拉。
