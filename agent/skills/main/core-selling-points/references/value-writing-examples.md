# 用户真实样例：从商品信息到营销卖点

这些是2026-10-20核对的用户七组输入样例的写作参考，不是目标商品事实或原作者真实提示词。任务中只迁移表达方法；不把参考商品的参数、背书、功效或优惠复制给当前商品。

## 1. 产品5：功能如何减少具体麻烦

原件：产品5/直播小米2万.rtf，章节“二、核心卖点（直播口播版，卖点＋用户利益）”。

|已给信息|原文卖点表达|可复用的方法|
|---|---|---|
|自带快充线，线也可作挂绳|“自带33W Type-C快充线，线即是挂绳……不用额外携带数据线……长途出行再也不会忘带充电线。”|功能不是停在接口名称，而是让外出少带一件、少操心一件；本商品是否真的有该功能仍按自己的资料判断。|
|自带线及额外接口，可同时为两台设备供电|“双接口设计，可同时给两台设备供电……手机＋蓝牙耳机/平板可以同时充电，多人同行不用抢充电宝。”|把结构设计转成具体使用情境与顾客价值，标题给亮点，正文给动作和场景。|

这类表达比“接口写清楚、下单前核对数量”更接近购买理由。原文中的“再也不会”等绝对措辞不必照搬，学的是价值转译。

## 2. 产品6：胶囊如何组织人群、复杂特征和主利益

原件：产品6.xlsx；“小紫瓶试镜”!A6/B6、“紫瓶plus（副本）”!A16/B16、“小紫店播话术”!A10/C10。表格本身是手卡和话术，没有独立生成日志，以下是写作分析。

- 原材料围绕多种成分组合，卖点用“一瓶顶4瓶”组织记忆点：它试图把复杂配方转成少买、少记、少操作的便利诉求。可学习“组合设计→一个主要利益”，不能由四种成分直接推出疗效等于四种单品。
- 原材料将成分含量、形态等归为一个主张，避免堆满参数；可学习选择与顾客决策最有关的少量特征，而不是把整张规格表改成标题。
- 原文先写目标顾客日常困扰，再接产品主张，且明确采用FAB框架。可学习Feature（特征）→Advantage（为何有用）→Benefit（顾客得到什么），以及不同人群如何决定卖点排序。
- 技术术语用生活类比帮助理解。类比只解释已有事实，不用类比证明新能力。

这些样例含未经本任务核验的抗老功效、剂量、倍数、安全和机构背书宣传。它们不是可复用的事实，不为文案好看就复制功效保证或夸大焦虑。当前商品仍只用自己的已知信息及用户确认。

## 3. 当前失败样例怎么识别

|失败写法|为何不够|改写方向|
|---|---|---|
|材质说清楚，选购更有底|讲的是介绍清楚，不是产品能帮顾客什么|若无与顾客价值有关的材质依据，换更有价值的角度，不硬编耐用性。|
|不是只买一支球拍，选购时把套装内容看清楚|只是清单和核对提醒|寻找组合设计对真实准备/使用过程的意义，避免承诺所有配件齐全或免安装。|
|三种颜色，按喜好选|属性可用，但可能不值得占据核心位置|与更强的功能、场景购买理由比较后再决定是否保留，不因有颜色字段就必须写。|

质量目标：读完能回答“我为什么要买、适合什么时候用”，同时能回到本商品事实找到依据。自然营销和事实可靠需要同时达到。
