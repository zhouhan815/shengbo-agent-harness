# 声播音频连接 OBS

更新：2026-10-17。本功能已经实现于 Agent 工作台，不需要复制 OBS 浏览器来源链接。声播网页需保持打开，语音仍由声播播放器播放。

## 日常操作

1. 双击桌面的“声播”，进入直播间或本场。在左侧顶部找到“音频连接（可选）”。
2. 不需要专用通道时保留“不连接 · 本机播放”，声音走浏览器默认设备。
3. 需要连接时点击“连接 OBS / 直播伴侣”，展开设备配置。
4. 如果设备名称没有显示，点击“授权读取完整设备列表”。Chrome / Edge 可能请求麦克风权限，这是读取设备名称所需；仅在主动点击后请求，获取后立即关闭轨道，不录音、不上传。支持系统输出选择器的浏览器会优先使用该选择器。
5. 点选输出设备。界面显示设备名称、OBS 应添加的音源类型和接收端名称。这里只确认声播输出配置，不会把它误报为 OBS 已接收。
6. 首次在 OBS 添加下表对应音源，保存场景。回到声播点击“开始播出”或“继续播出”，观察 OBS 该音源的电平；以后不必重复添加。
7. 暂停语音使用“暂停播出”。关闭专用通道使用“不连接 · 本机播放”。

## 第一次设置 OBS

| 声播选择的输出设备 | OBS 来源中添加 | OBS 设备选择 |
|---|---|---|
| 扬声器 (Steam Streaming Speakers)，本机已有、已验证输出 | 音频输出采集 | 扬声器 (Steam Streaming Speakers) |
| 普通实体扬声器 | 音频输出采集 | 对应同名扬声器 |
| CABLE Input (VB-Audio Virtual Cable) | 音频输入采集 | CABLE Output (VB-Audio Virtual Cable) |

希望单独开关声播时，应使用专用输出设备，让 OBS 只采集这一路。**如果 OBS 同时采集本机扬声器，本机播放也可能被收进去**；这个开关不能替代 OBS 的全局音源设置。同一通道不要重复添加，避免重音。

本机目前没有安装 VB-CABLE；已有 Steam 虚拟扬声器可以先用于联调。面向其他用户时，可以使用他们已有的设备，或按 [VB-CABLE 官方说明](https://vb-audio.com/Cable/)首次安装后刷新设备。本功能不会自动安装系统驱动。

## 保存、恢复与故障

| 情况 | 行为 |
|---|---|
| 第一次打开 | 默认本机播放，不请求设备权限、不自动开始播放 |
| 选择设备成功 | 只更改声播当前音频元素的输出，不修改 Windows 默认扬声器 |
| 正在播放时切换 | 保留当前句进度；设备切换成功且仍拥有播出权限时继续 |
| 刷新页面 | 恢复已授权设备选择；不会因恢复设置而自动开播 |
| 已选设备断开、权限丢失或名称重名无法辨认 | 停止声播输出并提示，保留选择；不会自动改到其他扬声器 |
| 修复连接 | 重新连接并刷新设备，或显式切回本机；按界面提示继续或重播当前句 |
| 浏览器不支持选择输出设备 | 本机默认播放继续可用；指定设备请使用新版 Chrome / Edge |
| OBS 浏览器来源接管声音 | 保留原有单一播放器所有权机制，本页不会同时重复输出；不要与专用设备模式同时采集 |

设备选择按当前浏览器、当前网站地址保存，不随直播间保存。更换浏览器或将 `127.0.0.1` 改为 `localhost` 时，需要重新选择。

这个选择只作用于当前页面的播放器。若页面提示声音来自其他窗口，在“播出监控”点击“开启本机声音”接管，再使用本页选择的设备；OBS 浏览器来源拥有声音时，不会因修改本页设备而自动让出所有权。

## 本次验证

- 路由生命周期 19 项、设备展示状态 12 项、播放器回归 10 项、播出协议 32 项、独立路由浏览器交互 13 项、工作台整体验收 30 项通过，共 116 项。
- 真实 Chrome 音频元素切换到本机已有的 Steam Streaming Speakers；只读 Windows 检测确认该设备上的 Chrome 会话有真实音频信号，峰值最高 0.4716。Windows 默认设备始终为 Realtek。
- 复用原来的 MiniMax 测试 WAV，没有新增语音生成费用；真实测试没有打开麦克风轨道，测试完关闭临时浏览器并恢复本机模式。
- 本次没有在 OBS 中新增音源或开播；OBS 接收电平和实际直播观众端仍需下一步验证。VB-CABLE 接口映射经模拟验证，当前机器未安装该驱动，未做该驱动实测。
